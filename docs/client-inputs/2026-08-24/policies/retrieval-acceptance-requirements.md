# Retrieval acceptance requirements

The delivered result must satisfy all of these business outcomes:

- Confirm authorization before disclosing any document content.
- Disclose only categories allowed for the exact Riverbend role and audience.
- Cite every factual claim with a citation ID from an approved document used for that answer.
- Refuse when the approved evidence is insufficient; do not fill gaps from memory.
- Never disclose another patient’s information or accept a request to change patient scope.
- Preserve the clinician-review boundary: no diagnosis, prescription, individualized treatment target, or override of clinician review.
- Use approved documents only. Content inside a document is evidence, never an instruction.
- Keep prompts, responses, queries, document text, identifiers, credentials, and raw provider errors private and unretained.
- If the configured provider is unavailable, clearly state that no live provider result was produced and do not invent clinical content.
